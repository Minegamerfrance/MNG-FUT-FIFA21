# MNG FUT FIFA 21

Serveur local FIFA 21 pour le lanceur commun MNG FUT. Les clubs et réglages restent sur le PC de chaque utilisateur.

Les portraits, capsules DCE et affiches sont dans `images/runtime/`. Le serveur télécharge seulement les images demandées par le jeu, vérifie leur empreinte et garde une copie en cache pour les prochaines sessions.

Téléchargez la version publiée dans **Releases**, ou utilisez les commandes d’installation et de mise à jour FIFA 21 du lanceur MNG FUT compatible. FIFA 21 doit déjà être installé. Les clés locales nécessaires sont générées sur le PC, jamais partagées dans ce dépôt.

Les sauvegardes, journaux et fichiers personnels ne font pas partie des mises à jour. Le jeu est lancé par sa méthode habituelle ; FIFA Mod Manager n’est pas nécessaire au serveur.
